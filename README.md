# Moon Client — Stage 1

Minecraft 1.21.11 | Fabric | Java 21

This is a starter project with a Right Shift screen and basic config foundation. The menu buttons are placeholders; HUD modules and skin importing are not implemented yet.

Upload the folder contents to GitHub. Run Actions → Build Moon Client and download the Moon-Client artifact. Install the JAR with Fabric API for Minecraft 1.21.11.
